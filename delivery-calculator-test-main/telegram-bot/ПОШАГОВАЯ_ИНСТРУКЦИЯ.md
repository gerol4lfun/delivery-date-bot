## ШАГ 2: Зарегистрироваться на Railway.app (5 минут)

### Что делать:

1. Откройте в браузере: https://railway.app
2. Нажмите кнопку **"Start a New Project"** или **"Login"**
3. Выберите **"Login with GitHub"** (если нет аккаунта GitHub - создайте его бесплатно на github.com)
4. Разрешите Railway доступ к вашему GitHub
5. Вы попадете в Dashboard Railway

**Готово! ✅**

---

## ШАГ 3: Создать проект на Railway (3 минуты)

### Что делать:

1. В Railway Dashboard нажмите **"+ New Project"** (зеленая кнопка)
2. Выберите **"Deploy from GitHub repo"**
3. Если видите список репозиториев:
   - Выберите ваш репозиторий (если уже загружен на GitHub)
   - Или нажмите **"Configure GitHub App"** для доступа
4. Если репозитория нет на GitHub - переходим к ШАГУ 4

**Готово! ✅**

---

## ШАГ 4: Загрузить код на GitHub (если еще не загружен) (10 минут)

### Вариант А: Через GitHub Desktop (РЕКОМЕНДУЮ для не программистов)

1. Скачайте GitHub Desktop: https://desktop.github.com
2. Установите и откройте
3. Войдите в свой GitHub аккаунт
4. Нажмите **"File" → "Add Local Repository"**
5. Выберите папку `delivery-calculator-test-main`
6. Нажмите **"Publish repository"**
7. Выберите имя репозитория (например: `delivery-calculator`)
8. Нажмите **"Publish"**

**Готово! ✅**

### Вариант Б: Через веб-интерфейс GitHub

1. Зайдите на https://github.com
2. Нажмите **"+" → "New repository"**
3. Назовите репозиторий (например: `delivery-calculator`)
4. Нажмите **"Create repository"**
5. На странице репозитория нажмите **"uploading an existing file"**
6. Перетащите всю папку `delivery-calculator-test-main` в браузер
7. Нажмите **"Commit changes"**

**Готово! ✅**

---

## ШАГ 5: Подключить репозиторий к Railway (3 минуты)

### Что делать:

1. В Railway Dashboard нажмите **"+ New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Найдите ваш репозиторий в списке
4. Нажмите на него
5. Railway начнет автоматически определять проект

**Готово! ✅**

---

### Что делать:

1. Railway откроет настройки проекта
2. Нажмите на созданный сервис (будет называться как ваш репозиторий)

   **Переменная 2:**
   - Name: `SUPABASE_URL`
   - Value: `https://dyoibmfdohpvjltfaygr.supabase.co`

## ШАГ 7: Задеплоить бота (автоматически!)

### Что делать:

1. Railway автоматически начнет деплой после сохранения настроек
2. Перейдите во вкладку **"Deployments"** (слева)
3. Дождитесь, пока статус станет **"SUCCESS"** (зеленая галочка)
4. Это займет 2-3 минуты

**Готово! ✅**

---

## ШАГ 8: Проверить работу бота (2 минуты)

### Что делать:

1. Откройте Telegram
2. Найдите вашего бота (по username, который вы указали при создании)
3. Отправьте команду: `/start`
4. Бот должен ответить приветственным сообщением!

**Если бот отвечает - ВСЁ РАБОТАЕТ! 🎉**

## ❓ Если что-то не работает:

### Бот не отвечает:
1. Проверьте логи в Railway: вкладка **"Deployments"** → выберите последний деплой → **"View Logs"**
2. Убедитесь, что все переменные окружения добавлены правильно
3. Проверьте, что Root Directory = `telegram-bot`

### Ошибки в логах:
- Скопируйте текст ошибки и отправьте мне
- Я помогу исправить
