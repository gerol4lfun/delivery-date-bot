# Пошаговая настройка бота (без конфликтов)

## Важно: бот должен работать только в ОДНОМ месте — на Vercel

---

## ШАГ 1: Остановить бота везде, кроме Vercel

- **Railway** — зайди в проект → Settings → удали сервис или останови
- **Render** — останови сервис
- **Локально** — если запускал `node index.js`, останови (Ctrl+C)

Иначе два бота будут получать одни и те же сообщения.

---

## ШАГ 2: Vercel — подключить репозиторий

1. Зайди на [vercel.com/dashboard](https://vercel.com/dashboard)
2. Открой проект **delivery-bot-telegram**
3. **Settings** → **Git**
4. Если репозиторий не `gerol4lfun/delivery-date-bot`:
   - **Disconnect**
   - **Connect Git Repository** → выбери `gerol4lfun/delivery-date-bot`
   - Ветка: **main**

---

## ШАГ 3: Root Directory

1. **Settings** → **General**
2. **Root Directory** → **Edit**
3. Укажи: `delivery-calculator-test-main/telegram-bot`
4. **Save**

---

## ШАГ 4: Переменные окружения

1. **Settings** → **Environment Variables**
2. Должны быть:
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
   - `SUPABASE_URL` — URL проекта Supabase
   - `SUPABASE_SERVICE_ROLE_KEY` — Service Role Key из Supabase
   - `ADMIN_USER_ID` (опционально) — твой Telegram ID

---

## ШАГ 5: Новый деплой

1. **Deployments**
2. **Create Deployment** (или кнопка **Deploy**)
3. Выбери ветку **main**
4. Дождись зелёного статуса **Ready**

---

## ШАГ 6: Установить webhook в Telegram (один раз)

Подставь свой токен и открой в браузере:

```
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/setWebhook?url=https://delivery-bot-telegram.vercel.app/api/webhook
```

Ответ `{"ok":true}` — всё ок.

**Если домен другой** (например, `delivery-bot-telegram-xxx.vercel.app`) — возьми URL из Vercel → Deployments → последний деплой → **Visit** → скопируй домен.

---

## ШАГ 7: Проверка

Отправь боту в Telegram: `Москва с 15.03`

Должно прийти:
1. «Обрабатываю данные...»
2. Список городов
3. «Обновляю данные в Supabase...»
4. «Обновление завершено!» — за 2–5 секунд

---

## Если не работает

1. **Vercel** → Deployments → последний деплой → **Logs** — смотри ошибки
2. Проверь webhook: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` — в ответе должен быть твой Vercel URL
