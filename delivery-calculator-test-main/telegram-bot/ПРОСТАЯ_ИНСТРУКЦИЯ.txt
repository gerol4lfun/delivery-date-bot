║  ПРОСТАЯ ИНСТРУКЦИЯ - Запуск бота на Railway.app            ║
╚══════════════════════════════════════════════════════════════╝

ШАГ 1: Создать файл .env
─────────────────────────
1. Откройте папку telegram-bot
2. Создайте новый файл с именем: .env
3. Вставьте туда (подставьте свои значения):

TELEGRAM_BOT_TOKEN=<ТВОЙ_BOT_TOKEN>
SUPABASE_URL=<ТВОЙ_SUPABASE_URL>
SUPABASE_SERVICE_ROLE_KEY=<ТВОЙ_SERVICE_ROLE_KEY>

4. Сохраните


ШАГ 2: Зарегистрироваться на Railway
──────────────────────────────────────
1. Откройте: https://railway.app
2. Нажмите "Login with GitHub"
3. Разрешите доступ


ШАГ 3: Создать проект
──────────────────────
1. Нажмите "+ New Project"
2. Выберите "Deploy from GitHub repo"
3. Выберите ваш репозиторий (или загрузите код на GitHub сначала)


ШАГ 4: Настроить переменные
─────────────────────────────
1. Откройте созданный проект
2. Перейдите в "Variables"
3. Добавьте 3 переменные:

   TELEGRAM_BOT_TOKEN = <ТВОЙ_BOT_TOKEN>
   SUPABASE_URL = <ТВОЙ_SUPABASE_URL>
   SUPABASE_SERVICE_ROLE_KEY = <ТВОЙ_SERVICE_ROLE_KEY>


ШАГ 5: Настроить запуск
────────────────────────
1. Перейдите в "Settings"
2. Root Directory: telegram-bot
3. Start Command: npm start
4. Сохраните


ШАГ 6: Проверить
────────────────
1. Дождитесь деплоя (2-3 минуты)
2. Откройте Telegram
3. Найдите вашего бота
4. Отправьте: /start
5. Если бот ответил - ВСЁ РАБОТАЕТ! ✅
