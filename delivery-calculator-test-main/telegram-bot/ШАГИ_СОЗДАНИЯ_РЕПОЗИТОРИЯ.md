# 📝 Шаги создания отдельного репозитория для бота

## 🎯 Цель: Создать отдельный проект на GitHub только для бота

---

## ШАГ 1: Создать новый репозиторий на GitHub (5 минут)

### Что делать:

1. Откройте https://github.com
2. Войдите в свой аккаунт
3. Нажмите на **"+"** в правом верхнем углу
4. Выберите **"New repository"**

### Настройки репозитория:

- **Repository name:** `delivery-dates-bot` (или любое другое имя)
- **Description:** `Telegram bot for updating delivery dates` (опционально)
- **Visibility:** Выберите **Private** (чтобы код был закрыт) или **Public** (если не важно)
- **НЕ ставьте галочки** на "Add a README file", "Add .gitignore", "Choose a license"
- Нажмите **"Create repository"**

**Готово! ✅ У вас есть пустой репозиторий**

---

## ШАГ 2: Скопировать папку telegram-bot (2 минуты)

### Что делать:

1. Откройте папку `delivery-calculator-test-main` на вашем компьютере
2. Найдите папку `telegram-bot`
3. **Скопируйте** всю папку `telegram-bot` (Ctrl+C или Cmd+C)
4. Создайте новую папку где-нибудь (например, на Рабочем столе)
5. Назовите её `delivery-dates-bot` (или как хотите)
6. **Вставьте** туда скопированную папку `telegram-bot`

**Или проще:**
- Скопируйте папку `telegram-bot`
- Переименуйте копию в `delivery-dates-bot`
- Переместите её на Рабочий стол

**Готово! ✅ У вас есть отдельная папка для бота**

---

## ШАГ 3: Загрузить код на GitHub (10 минут)

### Вариант А: Через GitHub Desktop (РЕКОМЕНДУЮ - самый простой)

1. **Скачайте GitHub Desktop:**
   - Откройте https://desktop.github.com
   - Нажмите **"Download for macOS"** (или Windows, если у вас Windows)
   - Установите программу

2. **Откройте GitHub Desktop**

3. **Войдите в GitHub:**
   - Нажмите **"Sign in to GitHub.com"**
   - Войдите в свой аккаунт

4. **Добавьте репозиторий:**
   - Нажмите **"File" → "Add Local Repository"**
   - Нажмите **"Choose..."**
   - Выберите папку `delivery-dates-bot` (которую вы создали в ШАГЕ 2)
   - Нажмите **"Add repository"**

5. **Опубликуйте на GitHub:**
   - В GitHub Desktop нажмите **"Publish repository"** (кнопка вверху)
   - Убедитесь, что имя репозитория совпадает с тем, что вы создали (например: `delivery-dates-bot`)
   - **НЕ ставьте галочку** на "Keep this code private" (если хотите приватный - оставьте галочку)
   - Нажмите **"Publish repository"**

**Готово! ✅ Код загружен на GitHub**

---

### Вариант Б: Через веб-интерфейс GitHub (если нет GitHub Desktop)

1. **Откройте ваш новый репозиторий** на GitHub (который создали в ШАГЕ 1)

2. **На странице репозитория** вы увидите инструкции, но нам нужен вариант:
   - "...or push an existing repository from the command line"
   - **НО** мы сделаем проще - через веб-интерфейс

3. **Нажмите "uploading an existing file"** (или просто перетащите файлы)

4. **Откройте папку `delivery-dates-bot`** на вашем компьютере

5. **Выделите ВСЕ файлы** внутри папки (Ctrl+A или Cmd+A)

6. **Перетащите их** в окно браузера на странице GitHub

7. **Прокрутите вниз**, найдите поле **"Commit changes"**
   - Введите: `Initial commit` (или оставьте как есть)
   - Нажмите **"Commit changes"**

**Готово! ✅ Код загружен на GitHub**

---

## ШАГ 4: Проверить что всё загрузилось (1 минута)

### Что делать:

1. Откройте ваш репозиторий на GitHub
2. Убедитесь, что видите файлы:
   - `index.js`
   - `package.json`
   - `parser.js`
   - `supabase.js`
   - `README.md`
   - и другие файлы

**Если видите файлы - всё отлично! ✅**

---

## ШАГ 5: Создать файл .env (2 минуты)

### Важно: Этот файл НЕ должен попасть в GitHub!

1. Откройте папку `delivery-dates-bot` на вашем компьютере
2. Создайте новый файл с именем `.env` (точка в начале!)
3. Вставьте туда (подставьте свои значения):

```
TELEGRAM_BOT_TOKEN=<ТВОЙ_BOT_TOKEN>
SUPABASE_URL=<ТВОЙ_SUPABASE_URL>
SUPABASE_SERVICE_ROLE_KEY=<ТВОЙ_SERVICE_ROLE_KEY>
```

4. Сохраните файл

**Готово! ✅ Файл .env создан (он не попадет в GitHub благодаря .gitignore)**
