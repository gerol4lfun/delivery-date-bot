## 🚀 Что нужно сделать СЕЙЧАС:

### ШАГ 1: Установить зависимости (локально, для теста)

Откройте терминал в папке `telegram-bot` и выполните:

```bash
cd telegram-bot
npm install
```

---

### ШАГ 2: Создать файл `.env`

Создайте файл `.env` в папке `telegram-bot` со следующим содержимым (подставьте свои значения):

```
TELEGRAM_BOT_TOKEN=<ТВОЙ_BOT_TOKEN>
SUPABASE_URL=<ТВОЙ_SUPABASE_URL>
SUPABASE_SERVICE_ROLE_KEY=<ТВОЙ_SERVICE_ROLE_KEY>
```

---

### ШАГ 3: Протестировать локально (опционально)

```bash
npm start
```

Бот должен запуститься. Найдите его в Telegram и отправьте `/start`.

---

## 📝 Как использовать бота:

1. Найдите вашего бота в Telegram
2. Отправьте текст в формате:

```
Москва с 9.02

Питер с 8.02

```

3. Бот автоматически обновит данные в Supabase!
