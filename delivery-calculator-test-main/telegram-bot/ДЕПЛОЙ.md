# 🚀 Инструкция по деплою бота

## 📋 Варианты деплоя (все бесплатные)

### Вариант 1: Railway.app (РЕКОМЕНДУЮ) ⭐

1. **Зарегистрируйтесь** на https://railway.app (через GitHub)
2. **Создайте новый проект** → "New Project"
3. **Выберите "Deploy from GitHub repo"**
4. **Подключите ваш репозиторий** (или создайте новый на GitHub)
5. **Добавьте переменные окружения:**
   - `TELEGRAM_BOT_TOKEN` = `<ТВОЙ_BOT_TOKEN>`
   - `SUPABASE_URL` = `<ТВОЙ_SUPABASE_URL>`
   - `SUPABASE_SERVICE_ROLE_KEY` = `<ТВОЙ_SERVICE_ROLE_KEY>`
6. **Установите команду запуска:** `npm start`
7. Railway автоматически задеплоит бота!

**Бесплатный tier:** 500 часов/мес (достаточно для работы 24/7)

---

### Вариант 2: Render.com

1. **Зарегистрируйтесь** на https://render.com
2. **Создайте новый Web Service**
3. **Подключите GitHub репозиторий**
4. **Настройки:**
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node
5. **Добавьте переменные окружения** (как в Railway)
6. **Deploy!**

**Бесплатный tier:** Работает, но может "засыпать" после 15 минут бездействия

---

### Вариант 3: Heroku (если есть аккаунт)

1. Установите Heroku CLI
2. `heroku create ваш-проект`
3. `git push heroku main`
4. Добавьте переменные окружения через dashboard

## 🧪 Тестирование локально

### 1. Установите зависимости:

```bash
cd telegram-bot
npm install
```

### 2. Создайте файл `.env`:

Скопируйте содержимое из `.env.example` и заполните реальными значениями (уже заполнены в инструкции выше).

### 3. Запустите бота:

```bash
npm start
```

Вы должны увидеть:
```
✅ Supabase подключен
🤖 Бот запущен и готов к работе!
```

### 4. Протестируйте:

Откройте Telegram, найдите вашего бота и отправьте:
```
/start
```

Затем отправьте тестовые данные:
```
Москва с 9.02
Тула с 9.02
```

## 📝 Что делать после деплоя:

1. ✅ Найдите вашего бота в Telegram
2. ✅ Отправьте `/start` - должно прийти приветственное сообщение
3. ✅ Отправьте тестовые данные для проверки
4. ✅ Проверьте, что данные обновились в Supabase

## ⚠️ Важно:

- **НЕ коммитьте** `.env` файл в Git!
- **Service Role Key** - секретный, не публикуйте!
- Railway/Render автоматически используют переменные окружения из настроек проекта

---

## 🐛 Если что-то не работает:

1. Проверьте логи на хостинге (Railway/Render показывают логи)
2. Убедитесь, что все переменные окружения установлены
3. Проверьте, что бот запущен (должен быть статус "Running")
