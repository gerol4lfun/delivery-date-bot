## 🚀 Как загрузить папку telegram-bot в репозиторий:

### СПОСОБ 1: Через веб-интерфейс GitHub (САМЫЙ ПРОСТОЙ) ⭐

1. **Откройте ваш репозиторий:**
   - https://github.com/gerol4lfun/delivery-date-bot

2. **На странице репозитория** нажмите **"uploading an existing file"**
   (или просто перетащите файлы в окно браузера)

3. **Откройте папку `telegram-bot`** на вашем компьютере:
   - Путь: `/Users/pavelkulcinskij/Downloads/delivery-calculator-test-main/telegram-bot`

4. **Выделите ВСЕ файлы** внутри папки `telegram-bot`:
   - `index.js`
   - `package.json`
   - `parser.js`
   - `supabase.js`
   - `README.md`
   - и все остальные файлы
   - **НО НЕ ВЫБИРАЙТЕ** файл `.env` (он секретный!)

5. **Перетащите файлы** в окно браузера на GitHub

6. **Прокрутите вниз**, найдите поле **"Commit changes"**
   - Введите: `Initial commit` (или оставьте как есть)
   - Нажмите **"Commit changes"**

**Готово! ✅ Файлы загружены!**

---

### СПОСОБ 2: Через GitHub Desktop

1. **Откройте GitHub Desktop**

2. **File → Clone Repository**

3. **Вкладка "URL"**:
   - Вставьте: `https://github.com/gerol4lfun/delivery-date-bot.git`
   - Выберите папку для клонирования (например, Downloads)
   - Нажмите **"Clone"**

4. **Скопируйте файлы:**
   - Откройте папку `delivery-calculator-test-main/telegram-bot`
   - Скопируйте ВСЕ файлы (кроме `.env`)
   - Вставьте в клонированную папку `delivery-date-bot`

5. **В GitHub Desktop:**
   - Вы увидите все файлы как "Changes"
   - Введите сообщение: `Initial commit`
   - Нажмите **"Commit to main"**

6. **Опубликуйте:**
   - Нажмите **"Push origin"** (или "Publish branch")

**Готово! ✅**

## ⚠️ ВАЖНО:

**НЕ загружайте файл `.env` в GitHub!**

Этот файл содержит секретные ключи и должен оставаться только на вашем компьютере.

Файл `.env` уже в `.gitignore`, поэтому он автоматически не попадет в репозиторий.
